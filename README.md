# Minecraft clone

Unity `6000.3.9f1`. Abre `Assets/Scenes/World.unity` y pulsa Play.

- WASD: moverse
- Ratón: mirar
- Espacio: saltar
- Clic izquierdo: romper
- Clic derecho: colocar
- Rueda del ratón: cambiar el slot de la hotbar
- Teclas 1 a 9: elegir el slot de la hotbar
- Escape: mostrar u ocultar el cursor
- F3: overlay de rendimiento
